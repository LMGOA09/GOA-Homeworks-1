Demonstrating CSS Inheritance

The inner tags (child elements) are not styled directly. They inherit traits from their parent container classes.

1. Font Family Parent Container

This paragraph automatically inherits the monospace font family from the parent div.

2. Color Parent Container

This text is red because the color property propagates down to all children.

Even inline span tags inherit this red hue.

3. Text-Align Parent Container

This entire text block is perfectly centered. The child tags obey the alignment rules set on the container layout.

4. Font-Size Parent Container

This content scales up cleanly because it inherits the 22px base size explicitly declared on the parent selector.

5. Font-Style Parent Container

This child text naturally assumes an italicized layout configuration from the container rule.
